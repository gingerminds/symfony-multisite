# Installation

Install and configure [`gingerminds/symfony-core`](https://github.com/gingerminds/symfony-core)
first: this bundle registers its resources, menu entries, permissions and cache context into it.

## 1. Require the bundle

```bash
composer require gingerminds/symfony-multisite
```

Register it after the core (Flex does it for you) in `config/bundles.php`:

```php
return [
    // ...
    Gingerminds\CoreBundle\GingermindsCoreBundle::class => ['all' => true],
    Gingerminds\MultisiteBundle\GingermindsMultisiteBundle::class => ['all' => true],
];
```

## 2. Routes

```yaml
# config/routes/gingerminds_multisite.yaml — admin site switcher and translations refresh
gingerminds_multisite:
    resource: '@GingermindsMultisiteBundle/config/routes.php'
```

The site and language CRUD routes (`/admin/sites`, `/admin/languages`) are generated by the
core route loader, and the API ones (`/api/sites`, `/api/translations`) by API Platform: nothing
else to import.

## 3. Database

The bundle ships no migration (Symfony convention, as the core): generate it in the project.

```bash
bin/console doctrine:migrations:diff
bin/console doctrine:migrations:migrate
```

Tables: `sites`, `languages`, `site_language` (`is_default`), `site_front_urls` — the same schema
as `gingerminds/laravel-multisite`.

## 4. Permissions

```bash
bin/console gingerminds:permissions:sync
```

Creates `view|edit|delete sites`, `view|edit|delete languages`, `manage translations` and
`assign sites` (run it on every deploy, it is idempotent). Then grant them to the roles in the admin.

## 5. Optional: front translations from Google Drive

```dotenv
# .env
GINGERMINDS_MULTISITE_TRANSLATION_ENABLED=false
```

```yaml
# config/packages/gingerminds_multisite.yaml
gingerminds_multisite:
    translation:
        enabled: '%env(bool:GINGERMINDS_MULTISITE_TRANSLATION_ENABLED)%'
```

The Google service account credentials are encrypted with `APP_SECRET`: it must be set (the
bundle refuses an empty key) and stable — changing it makes the saved credentials unreadable.
See [Front translations](Translations.md).

`google/apiclient` ships a client for every Google API (hundreds of MB). Keep only Drive:

```json
{
    "scripts": {
        "pre-autoload-dump": "Google\\Task\\Composer::cleanup"
    },
    "extra": {
        "google/apiclient-services": ["Drive"]
    }
}
```

## 6. Optional: users restricted to some sites

Without it every user works on every site. To give some users access to some sites only, add the
interface and the trait to the project user (the core `User` overridden as usual):

```php
// src/Entity/User/User.php
use Gingerminds\MultisiteBundle\Model\SiteRestrictedUserInterface;
use Gingerminds\MultisiteBundle\Model\UserSitesTrait;

class User extends BaseUser implements SiteRestrictedUserInterface
{
    use UserSitesTrait;
}
```

Then generate and run the migration (`users.all_sites`, true by default: the existing users keep
every site, and the `user_sites` table):

```bash
bin/console doctrine:migrations:diff
bin/console doctrine:migrations:migrate
```

Grant `assign sites` to the roles allowed to edit the sites of the users. See
[Site access](SiteAccess.md) for the rules.

## 7. Admin

Log in to `/admin`: **Administration › Sites / Languages**. Create the languages, then the sites
with their languages and default language. As soon as there are two sites, the sidebar shows a
site switcher (above the user menu) scoping the admin lists to the chosen site.
